Welcome to **Aeria Shop** documentation.

Browse the topics below for setup, configuration, licensing, and policies.

## Development

Run commands in the theme root (`/`):

```bash
npm install
npm run dev
```

Open the local site (default [http://localhost:3000](http://localhost:3000)) to preview changes.

### Build

```bash
npm run build
```

Static output is written to `out/`. Base path is `/` when building inside the theme repo.

## Configuration

- [shop.json](./shop-json/) — Site title, social links, email
- [Product metadata (goods)](./goods/) — Product Markdown front matter
- [licenses.json](./licenses-json/) — License labels and descriptions
